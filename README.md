# WS2812B-RGB-LED-and-ESP32-Christmas-Tree-Decorations

# About
This is a build log on how I built custom christmas tree decorations with addressable LED lights and ESP32 microcontrollers that display custom lighting effects.

Features Include:
- Addressable LED strips for diverse effects.
- Fully water resistant 3D printed enclosure and power supply.
- Wireless ESP32 remote with an OLED display to view the current lighting preset.
- Clock-synced programming to line up lighting effects, even for different sized trees.
- Wireless communication between controller and decorations via ESP-NOW
- Modular firmware design allowing easy expansion of effects and presets.
- Low-latency updates for smooth transitions and synchronized animations.

# Design and Construction
## Design Considerations
Some goals I had for these decorations was to:
- Use addressable LED strips for more diverse lighting effects
- Low cost
- Modular design
- Reliable even in harsh weather
- Low-latency wireless control to prevent having to manually set each tree's effect.

Thankfully, to achieve these goals, there were already a lot of options on the market that I could use to make these trees a reality without having to design circuit boards and libraries from scratch.
